Arbitrum's most active retail-airdrop surface today isn't the original ARB drop (that closed in 2023) but the STIP / LTIPP program — the DAO grants ARB to dApps which then route it as user-incentives. Worth checking which apps are in the current round; rewards shift between dApps with each round.

The Jun 16 cliff is the standard monthly linear unlock running through Apr 2027 — historically ~2% of supply releases on the 16th. Predictable, well-known, but worth flagging in the calendar for farmers holding farmed ARB rewards.
